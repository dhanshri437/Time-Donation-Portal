# Time Donation Portal – Donate Time, Not Money

A web platform that enables users to donate time and skills instead of money to NGOs and individuals in need.

## Overview

Time Donation Portal is a social-impact web platform designed to connect volunteers with NGOs and individuals who need help. Instead of donating money, users can contribute their time and skills to meaningful tasks.

## Key Features

- Volunteer registration and profile creation
- Skill-based volunteer participation
- Task posting and browsing
- Volunteer application and task tracking
- Time donation and tracking workflows
- Digital certificate generation
- User-friendly and accessible interface

## Technology Stack

- React.js
- JavaScript
- HTML
- CSS
